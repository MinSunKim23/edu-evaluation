# 교육평가 교과목 소개 페이지

연성대학교 유아교육과 2학년 교직선택 「교육평가」(2학점) 교과목 소개 정적 웹페이지입니다.

- 주교재: 서동기·엄재춘, 『교육평가』, 동문사
- 구성: 15주 주차별 계획 · 팀 산출물 12종 · 학습성과 CO1~CO4 · 평가 기준 · 성적 반영 비율

이 저장소는 서로 독립된 페이지 두 개를 배포합니다.

| 주소 | 페이지 |
|---|---|
| `/` | 교과목 소개 |
| `/tools/` | 수업 도구 (퀴즈 · 타이머 · 모둠 · 피드백) |

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 교과목 소개 페이지 본문 (CSS·JS 내장, 외부 리소스 없음) |
| `tools/index.html` | 수업 도구 페이지 본문 (CSS·로고까지 내장한 단일 파일) |
| `404.html` | 잘못된 주소 접근 시 안내 페이지 |
| `.nojekyll` | GitHub Pages의 Jekyll 빌드를 건너뛰게 하는 표시 파일 |

두 파일 모두 외부 스크립트·CDN·폰트·API를 쓰지 않습니다. 인터넷이 끊긴 상태에서 파일을 직접 열어도 동작합니다.

## GitHub Pages 배포 방법

### 1. GitHub에 저장소 만들기

GitHub에서 새 저장소를 만듭니다(예: `edu-evaluation`). README·.gitignore 등은 추가하지 않고 빈 저장소로 만드세요.

### 2. 이 폴더를 저장소에 올리기

아래 명령에서 `USERNAME`과 `REPO`를 본인 것으로 바꿔 실행합니다.

```bash
git init -b main
git add .
git commit -m "교육평가 교과목 소개 페이지"
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

### 3. Pages 켜기

저장소 페이지에서 **Settings → Pages → Build and deployment → Source** 를 **Deploy from a branch** 로 두고, 브랜치는 `main`, 폴더는 `/ (root)` 로 지정합니다.

1~2분 뒤 아래 주소에서 페이지가 열립니다.

```
https://USERNAME.github.io/REPO/
```

### 4. 수정 후 다시 배포하기

`index.html`을 고친 뒤 커밋·푸시하면 자동으로 다시 배포됩니다.

```bash
git add index.html
git commit -m "주차별 내용 수정"
git push
```

## 로컬에서 미리 보기

`index.html`을 브라우저로 바로 열어도 되고, 로컬 서버로 확인하려면:

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 으로 접속합니다.

## 내용 수정 가이드

주차별 계획은 `index.html` 하단 `<script>` 안의 `WEEKS` 배열에서 관리합니다. 각 항목의 필드는 다음과 같습니다.

| 필드 | 내용 |
|---|---|
| `w` | 주차 번호 |
| `tag` | `""`(일반) / `"issue"`(최신 이슈) / `"event"`(전시·갤러리 워크) — 필터 버튼과 색상을 결정 |
| `label` | 주차 배지에 표시할 문구 |
| `title` | 주차 제목 |
| `theory` | 이론 항목 배열 |
| `book` | 교재 장 표기 |
| `act` | 팀활동 설명 |
| `out` | 팀 산출물 |
| `run` | 시간 운영 배분 |

색상은 `:root`의 CSS 변수에서 한 번에 바꿀 수 있습니다.

## 수업 도구 페이지 (`tools/index.html`)

수업 중에 쓰는 도구 네 가지를 한 화면에 담은 페이지입니다. 서버·로그인·자동 저장이 없고, 입력한 값은 브라우저 메모리에만 있다가 새로고침하면 사라집니다.

| 기능 | 하는 일 |
|---|---|
| 퀴즈 | 개념 확인 3문항. 보기를 누르면 즉시 정답·해설, 전체 결과, 다시 풀기 |
| 타이머 | 분·초 설정, 시작·일시정지. 초기화는 확인 → 실행 → 직전 상태 1회 복원 |
| 모둠 | `S001`~`S012` 가상 ID. 형식·중복 검사 후 인원 차이 최대 1명으로 무작위 배정 |
| 피드백 | `이해됨 / 더 설명 필요 / 질문 있음` 3범주 막대그래프. 전체 지우기도 1회 복원 |

실제 이름·학번·이메일·전화번호는 넣지 않습니다. 피드백 입력칸이 학번·연락처처럼 보이는 값을 막지만, 이는 형식 확인일 뿐 개인정보를 모두 찾아내지는 못합니다.

### 퀴즈 문항 바꾸기

`tools/index.html` 안 `<script>` 맨 위의 `QUIZ` 배열 한 곳만 고칩니다.

| 필드 | 내용 |
|---|---|
| `q` | 문항 |
| `options` | 보기 3개 (적은 순서대로 화면에 표시) |
| `answer` | 정답인 보기의 번호 — **첫 번째가 `0`**, 두 번째가 `1`, 세 번째가 `2` |
| `why` | 정답·오답 모두에 함께 보여 줄 해설 한 줄 |

문항을 바꿀 때는 `answer`와 `why`도 반드시 같이 고칩니다. 고친 뒤에는 브라우저로 파일을 직접 열어 보기를 눌러 보고, 빈 입력과 잘못된 입력도 한 번씩 확인합니다.

### 고친 뒤 배포하기

```bash
git add tools/index.html
git commit -m "퀴즈 문항 수정"
git push
```

1~2분 뒤 `/tools/` 주소에 반영됩니다.

### 다른 사본과의 관계

`tools/index.html`이 기준 파일입니다. 아래 두 가지는 사본이므로 자동으로 따라 바뀌지 않습니다.

- **AI Agent 실습 폴더의 `내_작업/index.html`** — 8차시 수업에서 만든 작업본. 기록용으로 두고, 앞으로의 수정은 저장소 파일에서 합니다.
- **Claude 아티팩트** — 발행 시점의 사본. 갱신하려면 Claude에게 다시 발행을 요청합니다.

## 남은 확인 사항

- **교재 장 매핑** — 각 주차의 "교재 ▸" 표기는 표준적인 『교육평가』 구성으로 잠정 배치한 것으로, 실제 목차와 대조해 확정이 필요합니다.
- **13·14주차 정책 사실관계** — 유보통합 추진 경과, 어린이집 평가제·유치원 평가의 현행 주기와 지표는 1차 출처(i-nuri.go.kr, moe.go.kr, kcpi.or.kr 등)로 재확인이 필요합니다.
- **학과 인재상·직무역량 연계 문구** — 확보되면 각 CO 아래에 추가할 수 있습니다.
